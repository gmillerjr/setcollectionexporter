    Start here

    1. In ESO, type /setexport and wait for “Ready”.
    2. Type /reloadui (or log out) so ESO writes the file.
    3. Click Import ESO SavedVariables above and pick SetCollectionExporter.lua from your SavedVariables folder (Documents\Elder Scrolls Online\live\SavedVariables).

    Or click Try sample export to see how the page works.

    Character research · eligibility by piece

    Known traits are character specific. A set requires its minimum trait count on each individual item research line. Eligibility below checks research only; materials, style, station access and crafting passives still apply.

    Unlocked = permanently recorded in the account sticker book on this server. Physical ownership is not scanned. Crafted sets have no sticker-book completion percentage. Hover or expand a set for exported bonuses; ESO-Hub links require internet and open only when clicked.
